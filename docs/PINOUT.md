## Hardware notes

**VADJ must be 1.8 V for SLVS-EC.** Banks 43, 64 and 65 all run from VADJ_FMC (default 1.8 V, MAX15301 U2). The SLVS-EC control pins and sensor I2C pull-ups on bank 64 assume 1.8 V, so leave VADJ at 1.8 V whenever J21 is used. The board files use LVCMOS18 on every VADJ pin.

**Fan control is active low.** HDC09_FAN_PWM drives Q15, which pulls the gate of the fan switch Q16 low. With the pin low, floating or unconstrained (R120 pull-down) the fan runs at full speed; driving it high turns the fan off. The port is named fan_pwm_n and board_ctrl_3bits defaults it to 0. PWM it active low for speed control.

**FMC LA30, LA32, LA33 are single-ended.** They land on HD bank 43. LA32 and LA33 are not on P/N pairs (LA32_P = L9N, LA32_N = L8P; LA33_P = L11N, LA33_N = L12P), so treat all three as single-ended LVCMOS18.

**200 MHz clock IO standard.** U7 is an LVDS oscillator on HPA_CLK0 (C3/C2). Bank 66 runs at 1.2 V for the MIPI cameras, so the board files use DIFF_SSTL12, the same choice AMD makes for LVDS oscillators in 1.2 V banks on the ZCU10x boards.

**200 MHz clock shares a nibble with CAM1 lanes 2/3.** C3/C2 are IO_L12P/N_T1U in bank 66, the same nibble as CAM1 D2 (B4/A4) and D3 (D4/C4). If you use CAM1 in 4-lane mode together with the 200 MHz clock, run placement early to check the native/component-mode nibble rules.

**Si570 starts at 300 MHz.** The Si570 (570BAB001614DGR) on GTH REFCLK0 powers up at 300 MHz. Reprogram it over PS I2C0 (mux channel 2) before bringing up GTH channels that need a different reference.

**Carrier EEPROM location.** The carrier EEPROM (M24C64, 0x51) is on PS I2C0 behind the mux (channel 3), not on SOM I2C1 (MIO24/25). Kria boot firmware does not auto-detect the carrier, so load the carrier device-tree overlay explicitly.

**Camera resets go through the PIC.** cam0_reset_n / cam1_reset_n are requests into PIC U4, which drives CAM_GPIO0 (pin 17) on J13/J14. The PIC firmware decides the final timing.
